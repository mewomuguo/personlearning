# Logic Lab 邏輯任務基地

漢字、數學、自然科學的雙語練習網站。直接以 GitHub Pages 提供靜態檔案。

## 台灣小學常用一千字

漢字字庫已由千字文改為 **1,000 個不重複的正體字**。選字以教育部《國小學童常用字詞調查報告書》字頻順序為依據，統一「裏→裡」、「台→臺」後去重，取前一千字；這是本專案選表，不是官方指定的一千字名單。

| 練習批次 | 字數 |
|---|---:|
| L1 | 200 |
| L2 | 200 |
| L3–L6 | 各 150 |

L1–L6 依常見程度排列，不代表學校年級。每包最多 20 字，提供台灣注音、例詞、詞義、英文輔助與字典部首。題型為例詞讀音、選字填詞、部首辨認、注音選詞；不用任意分組判斷「臥底」。可搜尋本級字詞、選包練習或開始整級衝刺。

## 維護

- `data/hanzi-1000.json`：可編輯的字卡來源。`zy` 是目標字在 `w` 例詞中的讀音，`wzy` 是完整例詞注音；`readings` / `wordReadings` 用於排除同音干擾項。`rank` 保留原字頻序號。
- `scripts/build-hanzi.cjs`：執行 `node scripts/build-hanzi.cjs` 更新 `js/data.js` 的漢字區，保留自然與神獸資料。
- `js/app.js`：React 介面、出題與進度。
- `css/style.css`：畫面樣式。
- [字表來源、內容說明與授權](docs/HANZI_SOURCES.md)。原先 HANDOFF 文件是舊版歷史紀錄，字庫現況以本文件為準。

驗證：`node tests/hanzi.test.cjs`、`node tests/math.test.cjs`。

進度保存在瀏覽器 localStorage（`logic-lab-v1`），不會自動跨裝置同步。換字庫保留原存檔；點亮數只統計新字表內曾答對的字，不把已移除的古字計入分母或點亮數。點亮不是掌握度。衝刺完成時寫入帳本，農場答題另計體力。
